# ML-Kaggle-playground
Данный проект посвящён задаче бинарной классификации, основанной на данных банка. Цель проекта — предсказать, подпишется ли клиент на срочный вклад в банке (bank term deposit) на основе различных клиентских характеристик и исторических данных. Задача формулируется как классификация с метрикой качества ROC-AUC, что позволяет оценивать качество ранжирования вероятностей положительного класса.

Датасет включает разнообразные признаки, такие как демографические данные клиентов, информация о предыдущих контактах с банком, экономические индикаторы и другие релевантные факторы. Проект включает этапы обработки и анализа данных, создание и обучение моделей машинного обучения, оптимизацию гиперпараметров и оценку качества модели.

Основная бизнес-цель — помочь банку эффективно идентифицировать потенциальных клиентов, склонных к оформлению срочного вклада, чтобы оптимизировать маркетинговые кампании и повысить конверсию клиентов.

# Установка и использование
Запуск командной строки от администратора

Управление окружением
<pre>
make create_environment  #Создаёт conda-окружение на основе файла environment.yml. Выполняется однократно при первом развёртывании проекта.

make requirements   #Обновляет зависимости в существующем conda-окружении в соответствии с environment.yml.
  
make activate      #Показывает команду для активации окружения в консоли.
</pre>
Очистка и форматирование кода
<pre>
make clean  #Удаляет все скомпилированные Python файлы и кеши.

make lint  #Проверяет стиль кода с помощью ruff без внесения изменений.

make format  #Автоматически исправляет стиль кода с помощью ruff.

make ruff_fix  #Запускает только исправление стиля кода без предварительной проверки.
</pre>
Тестирование
<pre>
make test #Запускает модульные тесты через pytest.
</pre>
Предобработка данных
<pre>
make handle_outliers_log  #Обрабатывает выбросы с логарифмированием.

make optimize_numeric_types  #Оптимизирует числовые типы в данных для экономии памяти.

make split_features_target  #Разделяет данные на признаки и целевой признак.

make split_train_val_test    #Делит данные на обучающую, валидационную и тестовую выборки.

make dataset      #Выполняет полный pipeline подготовки датасета.
</pre>
Создание признаков
<pre>
make features     #Генерирует и обрабатывает признаки для моделей.
</pre>
Обучение и оптимизация моделей
<pre>
make hyperparam_opt   #Запускает оптимизацию гиперпараметров с помощью Optuna.

make train_model    #Обучает модель XGBoost с заданными параметрами.
</pre>
Предсказание и оценка
<pre>
make predict        #Делает предсказания на новых данных.
</pre>
Визуализация
<pre>
make plots         #Строит графики и визуализирует результаты.
</pre>
Справка
<pre>
make help         #Выводит список всех доступных команд с описаниями.
</pre>
